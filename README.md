A single one-line joke about office life, written for the
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/c/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
competition on make.fun.

## The joke

> Our office wellness program is a plant: it's dead, and HR only waters it every time someone quits.

## How it works

`main.py` (pure stdlib Python 3.13) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), asserting
first that it is a single line of 1–200 characters, then verifying the file
it wrote matches the intended text byte for byte.
